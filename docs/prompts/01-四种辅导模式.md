# Prompt 链 01：4 种辅导模式设计

> 用途：在 Trae 中复制以下对话，形成"需求 → AI 生成 → 验证 → 迭代"的完整 Prompt 链。
> 导出后保存为参赛材料。

---

## 项目背景（首次对话必发）

```
我在做一个 Next.js + React + TypeScript + Tailwind 的 Web 应用，叫"AI 代码学习助手"。
项目路径：D:\Projects\AI-Code-Teacher
技术栈：Next.js App Router、React、TypeScript、Tailwind CSS
AI 模型：智谱 glm-4.7-flash，通过 /api/chat 代理调用，SSE 流式返回。

这个产品面向编程零基础的大学生，核心功能是：学生粘贴代码或报错，AI 用通俗中文和生活比喻帮他学习。

请帮我设计并实现 4 种辅导模式，每种模式有独立的系统 Prompt，切换模式后 AI 按对应风格回答。
```

---

## 第一轮：提出需求

```
请帮我实现 4 种辅导模式：

1. 逐行讲解（explain）：把用户提供的代码逐行拆解，说明每个变量、语句、控制流的作用，用通俗比喻帮助理解，最后总结关键知识点。

2. 找 Bug（debug）：用户可能粘贴报错信息或可疑代码。请定位错误根本原因，用通俗语言解释为什么报错，给出排查思路（包括如何打印调试），并给出修复后的代码。

3. 代码优化（optimize）：对用户提供的代码给出命名、结构、可读性和性能方面的改进建议，解释每条建议的原因，并给出优化后的完整代码。

4. 出练习题（practice）：根据用户描述的知识点生成 3 道由易到难的练习题（入门/进阶/挑战），每题给出题目和思路提示，最后用分隔线给出参考解答。

要求：
- 在 src/lib/modes.ts 中定义模式类型和 4 种模式的配置（id、label、description、placeholder、systemPrompt）
- 每种模式的 systemPrompt 要明确角色是"面向编程零基础大学生的 AI 代码学习助手"
- 所有回答用简体中文
- 导出 MODES 数组、MODE_LABEL 映射、systemPromptFor 函数
- 代码要有 TypeScript 类型定义
```

---

## 第二轮：验证与追问（AI 生成后发）

```
检查一下：
1. 4 种模式的 placeholder 是否能引导用户输入正确的内容？
2. debug 模式的 systemPrompt 是否明确说了"用户可能只粘贴报错信息，也可能粘贴代码+报错"？
3. practice 模式是否要求了"鼓励学生先自己动手再对照答案"？
4. 类型定义是否完整，ModeId 是否是联合类型而不是 string？

如果有问题请修正。
```

---

## 第三轮：迭代优化

```
我觉得逐行讲解模式还不够好。请优化它的 systemPrompt：
- 要求 AI 在讲解时用"生活比喻"，比如把变量比作"贴了标签的盒子"
- 要求每讲解 3-5 行就插入一个"💡 通俗比喻"小段
- 结尾的知识点总结要用列表，每个知识点一句话说清
- 不要用太专业的术语，必须让完全没学过编程的人能看懂

另外，找 Bug 模式增加一个要求：如果用户只给了报错信息没有给代码，要先请用户补充相关代码，再做分析。
```

---

## 第四轮：确认完成

```
现在 4 种模式都实现好了。请确认：
- modes.ts 导出了 MODES、MODE_LABEL、systemPromptFor
- 每种模式有独立的 systemPrompt
- TypeScript 编译通过（npx tsc --noEmit）
- 模式切换时 UI 上的 placeholder 和描述会跟着变

完成后告诉我。
```
