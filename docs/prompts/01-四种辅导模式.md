这个产品面向编程零基础的大学生，核心功能是：学生粘贴代码或报错，AI 用通俗中文和生活比喻帮他学习。

具体要求：
1. 逐行讲解（explain）：把用户提供的代码逐行拆解，说明每个变量、语句、控制流的作用，用通俗比喻帮助理解，最后总结关键知识点。
2. 找 Bug（debug）：用户可能粘贴报错信息或可疑代码。请定位错误根本原因，用通俗语言解释为什么报错，给出排查思路（包括如何打印调试），并给出修复后的代码。
3. 代码优化（optimize）：对用户提供的代码给出命名、结构、可读性和性能方面的改进建议，解释每条建议的原因，并给出优化后的完整代码。
4. 出练习题（practice）：根据用户描述的知识点生成 3 道由易到难的练习题（入门/进阶/挑战），每题给出题目和思路提示，最后用分隔线给出参考解答。

export const MODE_LABEL: Record<ModeId, string> = {

export function systemPromptFor(mode: ModeId): string {

这个文件定义了：

- `MODE_LABEL` 映射，用于消息气泡显示模式名称
