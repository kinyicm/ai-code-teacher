# Prompt 链 03：多轮对话上下文

> 用途：在 Trae 中复制以下对话，形成"需求 → AI 生成 → 验证 → 迭代"的完整 Prompt 链。
> 这个功能涉及状态管理、API 改造和中断处理，能展示复杂交互的 AI 协同能力。

---

## 项目背景（首次对话必发）

```
项目：AI 代码学习助手（Next.js + React + TypeScript + Tailwind）
路径：D:\Projects\AI-Code-Teacher
现有结构：
- src/app/page.tsx — 主页面，streamChat 函数调用 /api/chat
- src/app/api/chat/route.ts — 智谱AI流式接口，接收 messages 数组
- 对话历史保存在 localStorage（key: ai-code-teacher-messages）

当前问题：每次发送只传当前一条消息，AI 没有上下文。
学生问完"这段代码什么意思"后，追问"那第三行呢"，AI 不知道之前讲了什么。
需要实现多轮对话：把历史消息一起发给AI，支持上下文追问。
同时要加一个"停止生成"按钮，生成过程中可以中断。
```

---

## 第一轮：提出需求

```
请帮我实现多轮对话上下文和停止生成功能：

1. 修改 streamChat 函数：
   - 增加 history 参数：{ role: "user" | "assistant", content: string }[]
   - 增加 signal 参数：AbortSignal（用于中断）
   - 构造请求时：system prompt + 历史消息（最近10条）+ 当前用户消息
   - fetch 时传入 signal

2. 修改 handleSubmit：
   - 从当前 messages 中构造历史：过滤掉空内容和错误提示（以 "> ⚠️" 或 "> （" 开头的）
   - 创建 AbortController，存入 ref
   - 调用 streamChat 时传入 history 和 controller.signal
   - catch 中处理 AbortError：用户主动中断时，保留已生成内容，追加"（已停止生成）"提示

3. 添加 handleStop 函数：调用 abortRef.current?.abort()

4. UI 修改：
   - 生成中（isThinking）时，发送按钮变成红色"停止生成"按钮
   - 点击停止按钮调用 handleStop
   - 停止后按钮恢复为"发送"

5. 要求：
   - 历史消息限制最近 10 条（5轮对话），避免 token 超限
   - 中断时不能丢失已生成的内容
   - 中断后可以继续发送新消息
   - TypeScript 类型完整
   - 不影响现有的 localStorage 保存逻辑
```

---

## 第二轮：验证与追问（AI 生成后发）

```
检查一下：
1. 历史消息构造时，是否把 assistant 的空内容（正在生成中的）过滤掉了？
   如果不过滤，会把空的 assistant 消息发给AI，可能导致异常。
2. AbortError 的判断是否正确？fetch 中断时抛出的是 DOMException，name 为 "AbortError"。
3. 中断后，isThinking 是否正确重置为 false？
4. 停止按钮的样式：红色边框+红色文字+半透明红背景，hover时加深。
5. 历史消息的 role 是否正确映射？user 和 assistant 都要传给AI。
6. 如果用户连续点击发送，会不会有问题？isThinking 时应该禁用发送。

有问题请修正。
```

---

## 第三轮：迭代优化

```
我测试了多轮对话，发现一个问题：
当AI回答很长时，历史消息会越来越多，可能超过 token 限制。
请优化：

1. 历史消息不仅限制条数（最近10条），还要限制总字符数（比如 8000 字符）。
   如果超过，从最早的消息开始截断，直到总字符数在限制内。

2. 增加一个"复制回答"按钮：
   - 每个 AI 回答气泡的右上角显示"复制"按钮
   - 点击后把该回答内容复制到剪贴板
   - 复制成功后按钮文字变成"已复制 ✓"，2秒后恢复
   - 空内容时禁用

3. 停止生成的体验优化：
   - 停止后，如果AI完全没有生成内容，显示"（已停止生成）"
   - 如果已经生成了部分内容，在内容末尾追加"\n\n_（已停止生成）_"
   - 不要显示错误提示，因为这是用户主动操作

4. 确认多轮对话能正常工作：
   发送第一段代码 → AI讲解 → 追问"那x变量是什么" → AI能基于上下文回答
```

