# Prompt 模板 03：多轮对话上下文

> 用途：在 Trae 中复制以下 Prompt 发送，真实 AI 回复由你实操后导出。
> 涉及状态管理、API 改造和中断处理，展示复杂交互的 AI 协同能力。

---

## 项目背景（第一条消息）

```
项目：AI 代码学习助手（Next.js + React + TypeScript + Tailwind）
路径：D:\Projects\AI-Code-Teacher
现有结构：
- src/app/page.tsx — 主页面，streamChat 函数调用 /api/chat
- src/app/api/chat/route.ts — 智谱AI流式接口，接收 messages 数组
- 对话历史保存在 localStorage（key: ai-code-teacher-messages）

当前问题：每次发送只传当前一条消息，AI 没有上下文。
学生问完"这段代码什么意思"后追问"那第三行呢"，AI 不知道之前讲了什么。
需要：①多轮对话（历史消息一起发给AI）②停止生成（可中断，保留已生成内容）③复制回答（一键复制）。
```

---

## 第 1 轮：提出需求

```
请实现：

1. 修改 streamChat 函数：
   - 增加 history 参数：{ role: "user" | "assistant", content: string }[]
   - 增加 signal 参数：AbortSignal（用于中断）
   - 构造请求：system prompt + 历史（最近10条，总字符≤8000）+ 当前消息
   - fetch 传入 signal

2. 修改 handleSubmit：
   - 从当前 messages 构造历史：过滤空内容和错误提示（以 "> ⚠️" 或 "> （" 开头的）
   - 从最新消息向前截断，直到总字符≤8000
   - 创建 AbortController 存入 ref
   - catch 中处理 AbortError：保留已生成内容，追加"（已停止生成）"

3. 添加 handleStop：调用 abortRef.current?.abort()

4. UI：
   - 生成中发送按钮变成红色"停止生成"按钮，点击调用 handleStop
   - 停止后恢复"发送"

5. 复制回答按钮：
   - 每条 AI 回答右上角显示"复制"，点击复制到剪贴板
   - 成功后显示"已复制 ✓"，2 秒恢复
   - 空内容禁用

6. 要求：中断后可继续发送新消息，TypeScript 类型完整，不影响 localStorage 保存。
```

---

## 第 2 轮：验证

```
检查：
1. 历史构造时是否过滤了正在生成中的空 assistant 消息？
2. AbortError 判断是否正确（DOMException，name 为 "AbortError"）？
3. 中断后 isThinking 是否重置？
4. 停止按钮样式是否红色边框+红色文字？
5. 历史消息 role 是否正确映射？
6. 中断后能否继续发送新消息？

有问题请修正。
```

---

## 第 3 轮：迭代优化

```
优化：
1. 中断提示：完全没生成内容时显示"（已停止生成）"；有部分内容时在末尾追加"\n\n_（已停止生成）_"。不要显示错误提示，因为这是用户主动操作。

2. 多轮对话测试：发送第一段代码→AI讲解→追问"那x变量是什么"→AI 能基于上下文回答。
```
