# AI 协同 Prompt 模板（参赛材料）

> 本目录只保存 Prompt 模板（你发给 AI 的指令）。
> 真实 AI 对话导出由你在 Trae 实操后，保存到 `export/` 子目录。
> 评审权重：过程可复现性与演进链路 25%、方法创新与意图控制 20%。

## 实操步骤

1. 打开 Trae，进入项目 `D:\Projects\AI-Code-Teacher`
2. 新建对话，复制对应模板的"项目背景"作为第一条消息
3. 按模板轮次发送 Prompt → 等 AI 生成 → 验证 → 发下一轮
4. 完成后导出真实对话为 Markdown
5. 保存到 `docs/prompts/export/` 目录
6. Git 提交

## 模板清单

| 编号 | 功能 | 迭代轮次 |
|------|------|----------|
| 01 | 四种辅导模式设计 | 4 轮 |
| 02 | 报错堆栈智能解析 | 4 轮 |

## 导出后提交

```bash
git add docs/prompts/export/
git commit -m "docs: 导出真实AI协同对话记录"
git push
```

## 注意

- 必须在 Trae 中**实际执行**对话，导出真实的 AI 回复，不能只提交模板
- 要体现"人提意图 → AI 生成 → 人验证修正 → AI 迭代"的过程
- AI 生成代码有 bug 时，你的修正过程本身就是"意图控制"的证据
