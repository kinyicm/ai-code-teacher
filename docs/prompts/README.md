# AI 协同 Prompt 链（参赛材料）

> 本目录保存 Trae 中 AI 协同开发的完整对话导出，作为传智杯 Vibe Coding 赛道的"过程可复现性"证据。
> 评审权重：过程可复现性与演进链路 25%、方法创新与意图控制 20%。

## 使用方法

1. 打开 Trae，进入项目 `D:\Projects\AI-Code-Teacher`
2. 新建一个对话，复制对应模板中的"项目背景"作为第一条消息
3. 按模板的轮次依次发送需求 → 等待 AI 生成 → 验证 → 发送下一轮追问
4. 完成所有轮次后，导出对话为 Markdown
5. 覆盖保存到本目录对应文件
6. Git 提交

## 已规划的 3 条核心 Prompt 链

| 编号 | 功能 | 迭代轮次 | 展示能力 |
|------|------|----------|----------|
| 01 | 四种辅导模式设计 | 4 轮 | 核心功能定义、系统 Prompt 工程、角色对齐 |
| 02 | 报错堆栈智能解析 | 4 轮 | 特色功能、边界处理、样式迭代、意图控制 |
| 03 | 多轮对话上下文 | 4 轮 | 复杂交互、状态管理、中断处理、体验优化 |

## 每条 Prompt 链的结构

每条链包含 4 轮对话，体现完整的演进过程：

1. **第一轮：提出需求** — 用自然语言描述功能目标和验收标准
2. **第二轮：验证与追问** — 检查 AI 生成的代码，指出潜在问题
3. **第三轮：迭代优化** — 基于测试反馈提出改进要求
4. **第四轮：确认完成** — 最终验收，确认所有要求满足

## 导出后提交

```bash
git add docs/prompts/
git commit -m "docs: 导出AI协同开发Prompt链（3个核心功能）"
git push
```

## 注意事项

- 必须在 Trae 中**实际执行**这些对话，导出真实的 AI 回复，不能只保存 Prompt 模板
- 对话中要体现"人提出意图 → AI 生成 → 人验证修正 → AI 迭代"的协同过程
- 如果 AI 生成的代码有 bug，你的修正过程本身就是很好的"意图控制"证据
- 导出时确保包含完整的代码块和对话上下文
