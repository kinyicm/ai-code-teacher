## 项目背景（第一条消息）

```
项目：AI 代码学习助手（Next.js + React + TypeScript + Tailwind）
路径：D:\Projects\AI-Code-Teacher
现有结构：
- src/app/page.tsx — 主页面，左侧输入区+右侧AI回答
- src/app/api/chat/route.ts — 智谱AI流式接口
- src/lib/modes.ts — 4种辅导模式
- src/components/CodeEditor.tsx — Monaco编辑器

当前"找 Bug"模式只能把报错原文直接发给AI。
我想做一个增强：用户粘贴 Java 异常堆栈时，前端自动解析出异常类型、错误消息、出错文件和行号，
生成面向零基础学生的通俗摘要，然后把摘要+原文一起发给AI，让回答更精准。
```

---

## 第 1 轮：提出需求

```
请帮我实现"Java 报错堆栈智能解析"：

1. 新建 src/lib/errorParser.ts，实现 parseJavaError(input: string)：
   - 识别输入是否是 Java 异常堆栈（包含 Exception/Error 或 "at " 堆栈行）
   - 提取异常类型（简短类名）和错误消息（冒号后的内容）
   - 提取出错位置：从 "at 包名.类名.方法(文件:行号)" 解析文件名和行号
   - 提取线程名（"Exception in thread xxx"）
   - 生成中文摘要

2. 内置常见 Java 异常通俗解释表（至少 15 种），覆盖大一常见异常：
   ArrayIndexOutOfBoundsException、NullPointerException、NumberFormatException、
   ArithmeticException、ClassCastException、IllegalArgumentException、
   IndexOutOfBoundsException、OutOfMemoryError、StackOverflowError、
   FileNotFoundException、IOException、InputMismatchException、
   SQLException、ClassNotFoundException 等

3. 在 page.tsx 中集成：
   - 用户输入时，如果检测到报错，在编辑器上方显示琥珀色提示条，展示解析结果
   - 发送时，把解析摘要+原始报错一起组装发给AI
   - 非报错输入不触发提示条

4. 要求：纯前端解析、不依赖额外库、TypeScript 类型完整、解析失败时降级为原文发送。
```

## 第 2 轮：验证

```
检查：
1. 用这段测试能否正确解析：
   Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5
       at com.example.Main.main(Main.java:12)
2. 通俗解释表是否覆盖大一常见异常？
3. 提示条是否只在检测到报错时显示？
4. 发送给AI的内容是否清晰区分"解析摘要"和"原始报错"？
5. 多个 at 行时，是否优先取用户代码（排除 java./javax./sun./jdk. 开头的）？

有问题请修正。
```

---

## 第 3 轮：迭代优化

```
优化：
1. 有些异常堆栈第一行直接是 "java.lang.XXXException: message"，没有 "Exception in thread"，要确保两种格式都能识别。

2. 提示条样式：琥珀色边框和背景、异常类型用等宽字体、通俗解释字号稍小、整体控制在 3-4 行。

3. 发送给AI的内容开头加一句："请基于以上解析结果，用通俗语言解释这个错误的原因和修复方法。"
```
